# Financial Sales Analysis — Methodology

## 1. Project Approach

This project follows a structured data analysis workflow to evaluate sales performance, profitability, regional trends, and customer segments.

## 2. Data Preparation

- Inspected the original dataset structure.
- Reviewed column names, data types, and data quality.
- Created a separate clean data worksheet.
- Standardized Product Name formatting.
- Preserved the original dataset in the RAW DATA worksheet.

## 3. Data Validation

- Compared raw and clean data row counts.
- Checked missing values and complete duplicate rows.
- Compared the original 19 columns between raw and clean data.
- Reviewed unique and repeated Order IDs and Customer IDs.
- Audited workbook formulas and repaired one broken formula reference.

## 4. Exploratory Data Analysis

The EDA worksheet was used to examine sales and profit patterns and prepare supporting calculations for business analysis.

## 5. Business Analysis

Pivot Tables were used to summarize:

- Sales and profit by category.
- Sales and profit by region.
- Sales and profit by customer segment.
- Sales trends by year.
- Product-level sales performance.

## 6. Dashboard Development

An interactive Excel dashboard was developed using KPI summaries, charts, Pivot Tables, and slicers.

Available slicers:
- Region
- Category
- Segment
- Ship Mode

## 7. Tools and Technologies

- Microsoft Excel
- Excel Formulas
- Pivot Tables
- Charts
- Slicers
- Data Cleaning
- Exploratory Data Analysis

## 8. Reporting

The final analysis communicates key performance indicators, business findings, and recommendations to support informed decision-making.
